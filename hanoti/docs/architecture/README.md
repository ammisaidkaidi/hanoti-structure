# Architecture reference material

[`baseline/`](baseline/README.md) contains historical backup and database-factory snapshots retained for comparison. It is separate from the maintained implementations under `packages/`, `api/` and `data/`.

This location is for architecture documentation and reference snapshots—not executable application code. The move does not adopt the old implementations or change the current database topology, connection policy, API contracts or business rules.

Test suites, fixtures, logs, archived one-off scripts and downloadable artifacts live in the sibling **`../.test/` relative to the Hanouti project root**, not inside this documentation folder or the application tree.
